在正式開始之前，先交代一下這個專案的技術立場。所有遊戲都是純 Vanilla HTML5 Canvas，零依賴，單一檔案就能部署。整套技術棧極簡到只有三樣東西：Canvas 2D API 負責繪圖、requestAnimationFrame 負責遊戲主迴圈、LocalStorage 負責資料持久化。沒有 Webpack、沒有 npm install、甚至連一個 import 都沒有。這種極簡主義聽起來很乾淨，但它同時也暴露了最真實、也最麻煩的問題——跨瀏覽器的相容性。因為你沒有框架幫你吸收平台的差異，所有瀏覽器實作的細微不同，都會赤裸裸地攤在你的代碼面前。這正是今天整集影片要深入剖析的核心：當 AI 在極簡環境下寫代碼，它在相容性上會踩到哪些坑，而自我修復管線又是怎麼把這些坑一個一個填起來的。
